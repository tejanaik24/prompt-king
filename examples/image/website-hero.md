# Example: Website Hero Prompt

This example demonstrates how Prompt King compiles a landscape website banner, managing horizontal compositions and copy room.

## User Request
> "Website hero image for a minimalist interior design studio. Space for a tagline on the left."

---

## Compiled Prompt King Output

### 1. SELECTED VISUAL TYPE
Website Mockup — Hero Section Banner (`WEBSITE_MOCKUP` + `NEGATIVE_SPACE`)

### 2. PURPOSE
Hero section visual for a luxury minimalist design agency website, providing a premium, calm aesthetic and clean dark/light space for copywriting text.

### 3. SELECTED COMMANDS
`WEBSITE_MOCKUP`, `NEGATIVE_SPACE`, `STUDIO_SOFTBOX`, `WOOD_TEXTURE`, `GLASS_TEXTURE`, `RULE_OF_THIRDS`, `16:9`

### 4. FINAL PRODUCTION PROMPT

```text
Create a website hero banner for a minimalist interior design studio.

Subject:
A highly curated corner of a modern, minimal living space. A single sleek oak lounge chair rests on a polished light concrete floor, next to a tall, slender green fiddle-leaf fig plant in a matte ceramic pot. Soft warm light falls across the wall behind.

Visual language:
Minimalist layout, architectural photography style, clean lines, luxury neutral color palette of off-white, oak wood, and soft gray.

Composition:
Asymmetrical composition following the rule of thirds. The furniture and plant are grouped on the right side of the frame. The left 60% of the image is occupied by a plain, clean, soft-textured beige wall, providing vast, distraction-free negative space for website copy text.

Camera:
Eye-level perspective, wide-angle lens (24mm equivalent) to emphasize space, deep focus ensuring clarity across both the chair and the wall texture.

Lighting:
Diffused studio softbox lighting from the side, simulating soft afternoon window light casting a gentle, elongated shadow of the chair onto the concrete floor.

Materials:
Polished concrete floor grain, matte ceramic glaze, physical oak wood fiber texture, woven linen chair cushion.

Environment:
Curated interior room corner with clean floor-to-wall junctions, zero clutter, and high-end design aesthetics.

Realism:
Realistic light reflections, physically plausible shadow falloff, subtle real-world textures, no plastic or artificial glossy sheen.

Mood:
Calm, spacious, serene, premium.

Aspect ratio:
16:9
```

### 5. ASPECT RATIO
16:9 (Standard website desktop hero ratio)

### 6. OPTIONAL NEGATIVE / AVOID LIST
*Generated via Negative Prompt Intelligence Engine (Negative base: `NEG-V1`)*
```text
Avoid: harsh shadows, busy background, blown-out highlights, cluttered composition, floating objects, cropped subject, generic AI art look, plastic surfaces, over-saturated colors, harsh glare, unreadable contrast, unnecessary decorative elements.
```
