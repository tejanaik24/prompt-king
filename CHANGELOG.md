# Changelog

## 0.3.0 — 2026-08-24
- **Concept Strength Engine** (first-class capability): judges concept
  originality BEFORE prompt drafting, the same way the Negative Prompt
  Intelligence Engine judges avoid-lists. Adds a `STRONG CONCEPT SIGNATURE`
  4-point test, a versioned cliché knowledge base (`CLI-V1` baseline:
  IDEA + PROP JUXTAPOSITION, TEMPLATE SELF-PROMO LAYOUT, SERVICE-LIST
  UNIFICATION METAPHOR, GENERIC ICON GRID, DISCONNECTED STOCK-PHOTO HERO)
  with a PUSH-DEEPER PROCEDURE, a COMPETITIVE DIFFERENTIATION CHECK, and a
  CONCEPT RISK CHECK (flags real cultural/religious/ethnic identity markers
  used as a punchline or prop rather than as the subject).
- **Viral Concept Generator**: shareability-specific criteria (tag-a-friend
  pull, technical surprise, silent-thumbnail readability, pattern interrupt
  against the category) layered on top of the Strong Concept Signature for
  requests that explicitly ask for viral, not just good.
- `VISUAL CONCEPT GENERATION` rewritten to generate genuinely different
  IDEAS (literalize fully / subvert the expected pairing / cut to the
  obvious-in-hindsight reduction / exploit format-native shareability /
  brief-specific metaphor) instead of five style variants of one idea.
- `VISUAL METAPHOR LIBRARY` entries now carry a push-deeper note — most are
  themselves common enough to fail the new CLICHÉ CHECK if used generically.
- Wired into `SELF-CRITIQUE LOOP` (new CLICHÉ CHECK + CONCEPT RISK CHECK
  steps) and `MASTER CREATIVE DIRECTOR RULE` (judges "weak" against the new
  engine's named tests instead of an undefined vibe check). Three new
  `QUALITY CONTROL SYSTEM` checks (21–23) for category-survival,
  differentiation, and shareability.
- Cliché knowledge base follows the same human-gated promotion path as the
  negative-prompt base — new categories only added from detected repeated
  patterns via the existing SELF-IMPROVEMENT SYSTEM, never invented
  mid-session.

## 0.2.0 — 2026-08-09
- **Negative Prompt Intelligence Engine** (first-class capability): the
  avoid list is now generated by a versioned, content-type-matched engine
  (`NEG-V1` baseline: HANDS / ANATOMY, TEXT / TYPOGRAPHY, FACES / EXPRESSION,
  STRUCTURE / COMPOSITION, STYLE DRIFT / GENERIC, PLATFORM / FORMAT FAILURE,
  CONTENT MISMATCH / POLICY) with platform filtering and a conflict check
  against the positive instructions. Wired into OUTPUT MODE, the default
  prompt structure's Avoid field, and a new NEGATIVE CHECK in the
  SELF-CRITIQUE LOOP.
- **Self-Improvement System** (Phases 0–6): SESSION CLOSE PROTOCOL captures
  experience records; a 13-stage, human-gated learning pipeline
  (OBSERVE → RECORD → … → PROMOTION GATE → … → MONITOR) improves the skill
  across sessions without ever letting the skill rewrite its own canonical
  behavior. Seven strictly-separated memory classes under `data/` + `rules/`,
  with protected invariants (`data/invariants.md`) and anti reward-hacking
  guardrails. Single-operator fallback documented (≥5 occurrences + benchmark
  pass + human approval + 180-day review).
- New scripts: `record-experience.ps1`, `detect-patterns.ps1`,
  `promote-rule.ps1`, `snapshot.ps1`, `rollback.ps1`.
- New docs: `docs/self-improvement-engine.md`, `docs/negative-prompt-engine.md`,
  `reference/negative-prompt-engine.md`.
- Tests: eval-suite scenarios 27–30 (negative-prompt engine) added;
  `tests/adversarial-suite.md` added (self-improvement hardening).
