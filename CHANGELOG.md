# Changelog

## 0.2.0 — 2026-08-09
- **Negative Prompt Intelligence Engine** (first-class capability): the
  avoid list is now generated by a versioned, content-type-matched engine
  (`NEG-V1` baseline: HANDS / ANATOMY, TEXT / TYPOGRAPHY, FACES / EXPRESSION,
  STRUCTURE / COMPOSITION, STYLE DRIFT / GENERIC, PLATFORM / FORMAT FAILURE,
  CONTENT MISMATCH / POLICY) with platform filtering and a conflict check
  against the positive instructions. Wired into OUTPUT MODE, the default
  prompt structure's Avoid field, and a new NEGATIVE CHECK in the
  SELF-CRITIQUE LOOP.
- **Self-Improvement System** (Phases 0–6): SESSION CLOSE PROTOCOL captures
  experience records; a 13-stage, human-gated learning pipeline
  (OBSERVE → RECORD → … → PROMOTION GATE → … → MONITOR) improves the skill
  across sessions without ever letting the skill rewrite its own canonical
  behavior. Seven strictly-separated memory classes under `data/` + `rules/`,
  with protected invariants (`data/invariants.md`) and anti reward-hacking
  guardrails. Single-operator fallback documented (≥5 occurrences + benchmark
  pass + human approval + 180-day review).
- New scripts: `record-experience.ps1`, `detect-patterns.ps1`,
  `promote-rule.ps1`, `snapshot.ps1`, `rollback.ps1`.
- New docs: `docs/self-improvement-engine.md`, `docs/negative-prompt-engine.md`,
  `reference/negative-prompt-engine.md`.
- Tests: eval-suite scenarios 27–30 (negative-prompt engine) added;
  `tests/adversarial-suite.md` added (self-improvement hardening).
