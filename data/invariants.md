# Invariants — Protected, Human-Owned

These are the non-negotiable behaviors of the prompt-king skill. The
self-improvement engine may **read** them but **never** modify them — they are
human-owned. Any proposed change to this file is a human decision, outside the
promotion gate.

1. **Canonical files are human-owned.** `SKILL.md` and `prompt-king.md` may
   only change with explicit human approval. The engine recommends; the human
   disposes.
2. **No self-approval.** The skill can never approve its own promotion, modify
   the eval suite, these invariants, or the promotion thresholds to make its
   own changes pass (anti reward-hacking).
3. **Single-session non-interference.** No canonical behavior change is made
   from a single session, however strongly it seems warranted.
4. **Content type before style.** The content type and purpose are always
   identified before any visual style or command is selected.
5. **No invented facts.** Research claims carry a source + date; when nothing
   solid is found, the skill says so instead of inventing.
6. **Conflicts surfaced, never silently resolved.** Contradictory instructions
   are flagged to the user — the output is a question, not a forced prompt.
7. **Negative lists are engine-generated.** Every avoid list is
   content-type-matched and conflict-checked (NEGATIVE PROMPT INTELLIGENCE
   ENGINE), never a generic throwaway tail.
8. **Confidentiality of experience records.** Records contain failure
   signatures only — no client data, no full prompts, no identifying details.
9. **Rollback over repair.** A failed deployed change is rolled back from a
   versioned snapshot rather than hot-patched.
10. **Traceability.** Every promoted change traces to a detected pattern, a
    benchmark result, and a human approval.
