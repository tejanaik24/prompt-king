# data/experiences/

Ephemeral experience records appended by SESSION CLOSE. One file per session,
format described in [`docs/self-improvement-engine.md`](../../docs/self-improvement-engine.md).

Record format (YAML):

```yaml
---
failure_code: HANDS / ANATOMY
content_type: BOOK_FRONT_COVER
symptom: character hand rendered with six fingers
context: cover illustration, cinematic style, publisher brief
severity: medium
occurrences: 1
source_user: false
---
```

Rules: only what the user reported or is directly observable; no client data,
no full prompts, no identifying details.
